Parkly 隐私政策

更新日期：2026年4月17日  |  生效日期：2026年4月17日

一、概述

Parkly（以下简称"我们"）深知个人信息对您的重要性，我们将按照法律法规的规定，保护您的个人信息及隐私安全。

二、我们收集的信息

1. 位置信息

  • 收集目的：用于定位附近停车场、计算停车场距离、地图展示
  • 收集方式：通过 GPS 定位获取
  • 使用场景：选择停车场、蓝牙断连时自动匹配最近停车场

2. 蓝牙设备信息

  • 收集目的：用于感知车载蓝牙连接状态，实现自动开始/结束停车
  • 收集方式：通过系统蓝牙接口获取已配对设备信息
  • 使用场景：蓝牙自动感知功能（需用户主动开启）

3. 停车记录数据

  • 收集目的：记录停车时间、费用、停车场等信息
  • 存储方式：本地 SQLite 数据库
  • 云端存储：仅在用户主动开启云同步后，数据加密上传至云端服务器

4. 设备信息

  • 收集目的：用于错误报告和应用改进
  • 收集内容：设备型号、系统版本、应用版本

三、信息使用

我们仅将收集的信息用于以下目的：

  • 提供停车计时和提醒服务
  • 计算停车费用
  • 展示附近停车场
  • 蓝牙自动感知停车
  • 数据云端备份（需用户主动开启）
  • 改进应用体验

四、信息共享

我们不会将您的个人信息出售、出租或以其他方式向第三方共享，除非：

  • 获得您的明确同意
  • 法律法规要求
  • 保护我们的合法权益

五、信息存储

  • 存储位置：中国境内（本地设备）及云端服务器
  • 存储期限：本地数据持续存储直至您卸载应用；云端数据持续存储直至您删除账号
  • 安全措施：数据加密传输和存储

六、您的权利

您有权：

  • 查询、更正您的个人信息
  • 删除您的停车记录
  • 关闭位置、蓝牙等权限
  • 注销账号并删除云端数据
  • 导出您的数据

七、未成年人保护

Parkly 主要面向成年驾驶人用户。如果您是未满18周岁的未成年人，请在监护人的陪同下阅读本政策。

八、第三方 SDK 说明

为保障应用功能，我们集成了以下第三方 SDK：

1. 高德地图 SDK

提供方：高德软件有限公司

用途：地理定位、POI 搜索、反向地理编码

收集信息：设备位置信息、设备标识信息、网络状态

隐私政策：https://lbs.amap.com/pages/privacy/

2. 极光推送 SDK

提供方：深圳市和讯华谷信息技术有限公司

用途：消息推送服务

收集信息：设备标识符、网络信息、设备型号

隐私政策：https://www.jiguang.cn/license/privacy

3. 友盟统计 SDK

提供方：友盟同欣（北京）科技有限公司

用途：应用使用数据统计分析

收集信息：设备标识符、设备型号、系统版本、应用使用行为

隐私政策：https://www.umeng.com/page/policy

4. Sentry SDK

提供方：Functional Software, Inc.

用途：应用崩溃监控和错误追踪

收集信息：设备信息、系统版本、崩溃日志

隐私政策：https://sentry.io/privacy/

5. Appwrite SDK

提供方：Appwrite Ltd.

用途：用户账号与数据云端同步（需用户主动开启）

收集信息：用户注册信息、同步的停车数据

隐私政策：https://appwrite.io/privacy

以上第三方 SDK 仅在您同意本隐私政策后初始化，未经您同意不会收集任何信息。
