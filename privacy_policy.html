Parkly 隐私政策

更新日期：2026年9月10日  |  生效日期：2026年9月10日

一、概述

Parkly（以下简称"我们"）深知个人信息对您的重要性，我们将按照法律法规的规定，保护您的个人信息及隐私安全。

二、我们收集的信息

1. 位置信息

  • 收集目的：用于定位附近停车场、计算停车场距离、地图展示
  • 收集方式：通过 GPS 定位获取
  • 使用场景：选择停车场、蓝牙断连时自动匹配最近停车场

2. 蓝牙设备信息

  • 收集目的：用于感知车载蓝牙连接状态，实现自动开始/结束停车
  • 收集内容：已配对蓝牙设备的名称及设备 MAC 地址（仅用于识别您主动绑定的车载蓝牙设备）
  • 收集方式：通过系统蓝牙接口获取已配对设备信息，仅保存在您的设备本地，不会上传
  • 使用场景：蓝牙自动感知功能（需用户主动开启）

3. 停车记录数据

  • 收集目的：记录停车时间、费用、停车场等信息
  • 存储方式：本地 SQLite 数据库
  • 云端存储：仅在用户主动开启云同步后，数据加密上传至云端服务器

4. 设备信息

  • 收集目的：用于错误报告和应用改进
  • 收集内容：设备型号、系统版本、应用版本

5. 应用列表信息（软件安装列表）

  • 收集目的：当您主动使用「分享」功能时，系统需查询您设备上可接收分享内容的应用，以向您展示分享应用选择面板；当您点击打开外部链接时，系统需查询可打开该链接的应用
  • 收集方式：通过系统接口查询可响应分享/打开动作的应用列表
  • 使用范围：仅在上述功能被您主动触发时即时使用，仅用于完成分享或跳转本身，我们不会存储该列表，也不会将其上传或用于任何其他目的

三、信息使用

我们仅将收集的信息用于以下目的：

  • 提供停车计时和提醒服务
  • 计算停车费用
  • 展示附近停车场
  • 蓝牙自动感知停车
  • 数据云端备份（需用户主动开启）
  • 改进应用体验

四、信息共享

我们不会将您的个人信息出售、出租或以其他方式向第三方共享，除非：

  • 获得您的明确同意
  • 法律法规要求
  • 保护我们的合法权益

五、信息存储

  • 存储位置：中国境内（本地设备）及云端服务器
  • 存储期限：本地数据持续存储直至您卸载应用；云端数据持续存储直至您删除账号
  • 安全措施：数据加密传输和存储

六、您的权利

您有权：

  • 查询、更正您的个人信息
  • 删除您的停车记录
  • 关闭位置、蓝牙等权限
  • 注销账号并删除云端数据
  • 导出您的数据

七、未成年人保护

Parkly 主要面向成年驾驶人用户。如果您是未满18周岁的未成年人，请在监护人的陪同下阅读本政策。

八、第三方 SDK 说明

为保障应用功能，我们接入了以下第三方服务：

1. 高德开放平台 Web 服务 API

提供方：高德软件有限公司

用途：POI 地址搜索、反向地理编码（仅在您使用地址搜索/选点功能时调用）

传输信息：您选择或搜索时的位置坐标、搜索关键词

隐私政策：https://lbs.amap.com/pages/privacy/

2. Appwrite SDK

提供方：Appwrite Ltd.

用途：用户账号与数据云端同步（需用户主动开启）

收集信息：用户注册信息、同步的停车数据

隐私政策：https://appwrite.io/privacy

以上第三方服务仅在您同意本隐私政策后初始化，未经您同意不会收集任何信息。

九、自启动与关联启动说明

为实现"停车自动感知"功能，当您在「设置」中主动开启「后台蓝牙监听」，并在弹窗中明确同意后，应用会且仅会在以下场景使用自启动能力：

1. 后台蓝牙监听服务被系统清理后，自动恢复该服务；

2. 设备重启后，自动恢复该服务。

上述自启动仅用于恢复蓝牙监听服务本身（用于感知车载蓝牙断连/重连、自动记录停车），不会启动应用界面，也不会关联启动任何第三方应用。

若您未开启该功能或未同意，应用不存在任何自启动行为。您可随时在「设置-后台蓝牙监听」中关闭该功能，关闭后自启动行为立即停止。
